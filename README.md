Java Övningar

Detta projekt innehåller flera övningar i objektorienterad programmering i Java.

Innehåll Arv med Animal Basklass Animal samt subklasserna Hyena och Lion som visar hur arv och metoder fungerar. Shape och area Klassen Shape med subklasserna Rectangle och Triangle. Visar hur man återanvänder kod med arv och super.

Bibliotekssystem Ett enkelt system med en ArrayList för att:

Lägga till böcker Söka och låna böcker Lista tillgängliga böcker Returnera böcker

Syfte Att träna på:

Arv och klasser Metoder och objekt Kodåteranvändning Listor (ArrayList)
